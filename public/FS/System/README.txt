eOS Desktop v2.0 "Liquid Glass"
================================

Добро пожаловать в eOS Desktop - современную операционную систему в браузере!

О СИСТЕМЕ
---------
eOS Desktop - это полноценная симуляция десктопной ОС, работающая прямо в вашем браузере.
Система использует формат приложений .eapp и виртуальную файловую систему.

ВОЗМОЖНОСТИ
-----------
• Liquid Glass UI - современный интерфейс с эффектом стекла
• Виртуальная файловая система с поддержкой drag & drop
• Система приложений .eapp (v1.0 и v1.1)
• Многозадачность с управлением окнами
• Системные настройки и персонализация
• App Store для установки приложений
• Терминал с системными командами

СИСТЕМНЫЕ ПРИЛОЖЕНИЯ
-------------------
• Настройки - персонализация системы
• Finder - файловый менеджер
• Терминал - командная строка
• App Store - магазин приложений
• Калькулятор - математические вычисления
• Заметки - простые заметки
• Часы - мировое время и секундомер
• TextEdit - текстовый редактор
• Мониторинг - системные ресурсы

ФАЙЛОВАЯ СИСТЕМА

ПРИЛОЖЕНИЯ .EAPP
----------------
Формат .eapp поддерживает две версии:

v1.0 (Legacy):
  - id, name, icon, color, code
  - Простые приложения

v1.1 (Modern):
  - version, eappVersion, supportedModels
  - isSystem, background
  - Расширенные возможности

API ДЛЯ ПРИЛОЖЕНИЙ
------------------
window.ePhone:
  - close() - закрыть окно
  - minimize() - свернуть окно
  - getSettings() - получить настройки
  - setSettings(obj) - установить настройки
  - getRBACLevel() - уровень доступа

window.ePhoneContext:
  - modelName - модель устройства
  - model - тип модели
  - isDesktop - десктоп режим
  - osVersion - версия ОС

window.ePhoneConsole:
  - execute(cmd) - выполнить команду

ГОРЯЧИЕ КЛАВИШИ
---------------
F3 / Ctrl+↑    - Mission Control
Cmd/Ctrl+W     - Закрыть окно
Cmd/Ctrl+M     - Свернуть окно
